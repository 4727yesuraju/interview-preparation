# 📚 What is the DOM?

## 📖 Simple English Explanation

**DOM** stands for **Document Object Model**.

The DOM is a **tree-like representation of an HTML document** created by the browser.

JavaScript uses the DOM to:

- Read HTML elements.
- Change HTML content.
- Change CSS styles.
- Add or remove elements.
- Respond to user actions like clicks and key presses.

> **Simple Definition:**
>
> **The DOM is a bridge between JavaScript and HTML. It allows JavaScript to access and modify a web page.**

---

## 🤔 Why is it Needed?

- Change webpage content dynamically.
- Update styles without reloading the page.
- Respond to user interactions.
- Create interactive web applications.

## ✍️ Syntax

### Select an Element

```javascript
const element = document.getElementById("title");
```

### Change Content

```javascript
element.textContent = "Hello JavaScript";
```

---

## 💻 Example

### Example 1: Change Text

**HTML**

```html
<h1 id="title">Hello</h1>
```

**JavaScript**

```javascript
const heading = document.getElementById("title");

heading.textContent = "Welcome!";
```

**Result**

```html
<h1 id="title">Welcome!</h1>
```

---

### Example 2: Change CSS Style

```javascript
const heading = document.getElementById("title");

heading.style.color = "blue";
```

---

### Example 3: Add a New Element

```javascript
const p = document.createElement("p");

p.textContent = "This is a paragraph.";

document.body.appendChild(p);
```

---

## 🎤 Interview Answer (30 Seconds)

The DOM, or Document Object Model, is a tree-like representation of an HTML document created by the browser. It acts as a bridge between JavaScript and HTML, allowing JavaScript to access, modify, add, or remove HTML elements and respond to user interactions such as clicks and keyboard events.
